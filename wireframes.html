⚑ UX Questions & Open Decisions
Q1 · Planner
How does the recipe picker work when tapping an empty slot?
Option A: Full-screen library search sheet, filtered by meal type. Option B: Expands quick-add strip inline with search. Option A is more powerful but more friction. Option B is faster for the 80% case of choosing a recent recipe.
Q2 · Planner
What does "Add to plan" do when tapped from Recipe Detail?
Does it open a day/slot picker, or add to the next empty slot automatically? The picker is explicit but adds taps. Auto-add is faster but may surprise the user. Given this is personal/single-user, a lightweight bottom sheet slot picker feels right.
Q3 · Planner
Week start day: Monday or Sunday?
Should respect device locale, but worth asking. Also: should the planner always open on the current week, or remember the last-viewed week?
Q4 · Shopping list
How are ingredients assigned to aisles?
Options: (A) Hardcoded lookup table, (B) User assigns category when adding ingredient, (C) AI inference at save time. Option A covers 90% of cases cheaply. Consider letting users reorder or rename sections for their specific supermarket.
Q5 · Shopping list
What happens when you edit the plan after generating the list?
Recommend: show a "Plan has changed — refresh list?" banner rather than auto-refreshing, to avoid disrupting an in-progress shop where items have already been checked off.
Q6 · Add Recipe
URL import: what happens when scraping fails?
Many recipe sites block scrapers. Options: use a recipe API (Spoonacular, Edamam), or integrate with the iOS Share Sheet so users can share from Safari to the app natively — most seamless for mobile but requires an App Extension.
Q7 · Recipe Detail
Should serves be interactive (scale ingredients)?
A serves stepper (− 2 +) that proportionally scales quantities would be genuinely useful, especially for the shopping list. Straightforward for structured ingredient data; harder for free-text quantities ("a handful"). Worth building from the start.
Q8 · Navigation
Should Recipe Detail be a modal or a push view?
Reachable from both Library (push view) and Planner (feels more like a modal). Consider presenting as a modal sheet from Planner, push view from Library — same content, two presentation styles.
